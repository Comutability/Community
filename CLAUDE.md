# Claude Code instructions for Comutability/Community

@AGENTS.md

This repo holds community documentation and governance, **not production application code**.

- Read `FOUNDING-CHARTER.md`, `OPERATING-HANDBOOK.md`, `policies/AI-AGENT-OPERATING-RULES.md` (draft), `docs/WEBSITE-AND-HOSTING-RULES.md` (draft) and the relevant handbook chapter before editing.
- **ChatGPT** is used as an ideas/research/briefing assistant; **Claude** is the implementation and creative engineering assistant; **Base44** remains a separate app builder/host for designated projects. **Humans** approve and release.
- No AI tool is a legal or community governance authority, regardless of its name.
- Respect the approved charter. Do not mark PR #1, #3, #4 or the unified handbook as ratified without a numbered, explicit human decision.
- Make changes on focused feature branches with PRs; do not merge, deploy or publish releases without explicit human approval.
- Always report tests actually run. Do not claim independent review or production readiness without evidence.
- Do not reveal credentials or private data, download unrelated personal files or alter Base44 deployments.
- Keep public documentation in UK English and preserve the existing no-em-dash prose style where practical.
- If you need new repository privileges, ask the founder before proceeding.
- When creating a new application, use `templates/PROJECT-README.md`, `templates/PROJECT-CLAUDE.md`, `templates/PROJECT-AGENTS.md`, and `templates/PROJECT-DEPLOYMENT.md` as reviewed starting points. Use `templates/BASE44-BUILDER-AGENT-RULES.md` when relevant. Choose a valid per-project OSS licence.
