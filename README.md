**Community + Usability**  
**Built together. Open to everyone.**

## How to contribute

You don't have to be a developer. You can propose a problem worth solving, test software, suggest usability or accessibility improvements, translate, document, design, review or code. Please be considerate and never post private credentials or sensitive personal information.

We are establishing community governance, contributor policies and release standards. **The founding charter is approved; governance policies are still proposals.** Our [first application concept, FileGuide](projects/001-fileguide/PROJECT-BRIEF.md), has been selected for discovery only: no implementation or release has yet been approved.

## Transparency

We will distinguish experiments from maintained releases, document important decisions and remain honest about AI assistance and independent testing. Contributions should be discussed publicly where appropriate, with sensitive security disclosures kept private.

## Licensing

This repository currently contains an Apache-2.0 `LICENSE` file. Individual future software projects may select different recognised open-source licences after review.

## Unified organisation handbook (proposal)

We are organising work around **ChatGPT for ideas and research**, **Claude for creative implementation**, **Base44 for designated existing apps**, and **GitHub for code, issues and reviews**. Human maintainers remain responsible for approvals and releases.
