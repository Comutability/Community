# Reporting security vulnerabilities

**Status: Proposed security guidance. Reporting contact not yet configured.**

Please do not publicly disclose unpatched vulnerabilities, credentials or personal information.

Once each software repository has a private vulnerability-reporting channel, use that channel to report the affected version, steps to reproduce, expected impact and any suggested mitigation.

Until a private channel is configured, **do not send sensitive exploit details through public GitHub issues**. The community must publish a confidential contact or enable GitHub private vulnerability reporting before inviting detailed submissions.

No release is claimed secure or independently audited merely because it is open source or AI-assisted.
