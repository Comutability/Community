# Decision 0002: Select FileGuide as the first discovery project

**Date:** 28 October 2026  
**Status:** Selected for discovery; implementation conditional on validation  
**Project:** FileGuide (working name)

## Decision

Choose **FileGuide**, an accessible, privacy-first, read-only desktop storage and duplicate-file guide, as the first Comutability application concept to research.

This selection advances the founding roadmap's **first application selection** milestone. It does **not** mean the need has been validated, development has begun, the licence is approved, or software has been released.

## Rationale

- Broad user problem, including nontechnical users organising ordinary files.
- Narrow, realistically testable first scope.
- Demonstrates community usability, accessibility, local-first privacy and safe defaults.
- No server, accounts or paid infrastructure are needed for core use.

Existing tools, notably Czkawka and dupeGuru, are capable and open source. Research must establish whether a new guided interface is justified or whether contributing upstream is a better use of community effort.

## Conditions

Complete the research and go/no-go gate in [Project 001 brief](../projects/001-fileguide/PROJECT-BRIEF.md) before creating an implementation repository or claiming a release schedule. Keep the entire v0.1 application read-only.

## Reconsideration

If user research does not identify a meaningful need, record the finding and either narrow, pivot or close the concept transparently.
