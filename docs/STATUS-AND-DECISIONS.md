## How to ratify a policy

1. Discuss it in its PR or public issue.
2. Address comments and any security/privacy contact gaps.
3. Make an explicit founder/community governance decision with date, scope, changes and owners.
4. Merge or publish a numbered `decisions/` record and update this register.
5. Apply actual GitHub rules, team access and CI; documentation alone is not technical enforcement.

The founding charter controls if proposed handbook text conflicts with it.
